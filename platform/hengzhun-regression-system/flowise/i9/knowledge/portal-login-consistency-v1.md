# 复兴银行门户登录与资料一致性规则

- 知识编号：`HZ-KNOW-PORTAL-LOGIN-001`
- 来源：复兴银行门户登录与个人资料业务契约
- 版本：`1.0.0`
- 适用范围：本机演示环境中的客户账号密码登录回归

## identity-consistency

客户使用账号密码登录复兴银行门户后，右上角必须显示当前认证账户的客户姓名与头像。右上角姓名必须与个人资料页的客户姓名一致；右上角头像所代表的当前客户身份必须与个人资料页一致，不得使用固定演示姓名、其他客户资料或脱离当前会话的占位身份。

## acceptance-evidence

验收至少保存以下脱敏事实：登录成功后的门户地址、右上角显示姓名、个人资料页客户姓名、两处头像身份一致性断言，以及每项断言的通过或失败状态。不得把账号、密码、Cookie、Token、完整 Storage State 或真实个人敏感信息写入知识、对话或证据摘要。

## execution-boundary

平台知识只解释业务语义和验收规则，不保存案例运行状态、脚本版本、调度、失败事件或人工决定。上述结构化事实只由 Harness `regression_platform.sqlite` 管理，平台通过认证 MCP 获取脱敏摘要。
