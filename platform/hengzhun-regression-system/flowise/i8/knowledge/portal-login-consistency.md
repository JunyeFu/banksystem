# 门户登录与个人资料一致性规则

复兴银行门户的普通客户使用用户名或手机号和密码登录。登录成功后，右上角显示的用户姓名必须与个人资料页中的客户姓名一致；头像必须来自同一当前登录账户，不能使用固定演示姓名或固定头像。

回归案例至少验证：登录成功、进入受保护页面、右上角姓名可见、个人资料姓名可见、两处姓名相等、头像归属于当前账户。凭据只通过受控别名由 Worker 在本地解析，任何 Agent、知识库、MCP 返回值和证据都不得包含密码、Token、Cookie 或 Storage State。

如果用户没有明确客户角色、期望结果存在互斥含义，或者动作包含高风险业务写入，主控必须先向用户提出一个业务澄清问题。不得向普通用户询问 namespace、幂等键、凭据别名、定位器、端口或 Cron。
