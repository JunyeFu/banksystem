# BANK-0401 execution report

Status: REVIEW

Added a channel-owned mock clearing service with idempotent submission and
deterministic `SUCCESS`, `TIMEOUT`, `DUPLICATE`, and `OUT_OF_ORDER` scenarios.
Callback delivery is at-least-once, sequence-aware, ignores duplicate sequence
numbers, reports out-of-order delivery, and signs callback material with
HMAC-SHA256 using an environment-only secret.
