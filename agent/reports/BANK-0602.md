# BANK-0602 execution report

Status: REVIEW

Added `scripts/backup/restore-core-drill.ps1`, which restores the Git-ignored
core custom-format archive into a temporary digest-pinned PostgreSQL container,
checks the restored public table count, and always removes the temporary
container. It never mounts or writes the live core data directory.

The channel backup companion scripts now cover the independent `bank_channel`
database: `create-channel-backup.ps1` produced a SHA-256 archive and
`restore-channel-drill.ps1` restored it into a temporary digest-pinned
PostgreSQL target with `public_tables=12`.
