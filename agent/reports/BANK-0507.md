# BANK-0507 execution report

Status: REVIEW

Added protected Operations API commands for savings account block, unblock,
close, and prematureClose. The adapter validates the command allowlist and
forwards the request through Fineract's local API; no core database write is
performed by the channel service.

The adapter was corrected from the local Swagger contract to send
`reasonForBlock` and close date fields. An authorized internal-realm block then
unblock sequence completed through the Gateway, and a direct Fineract read
confirmed the account returned to `Active` / `None` sub-status. Close and
premature-close remain intentionally unexecuted to preserve the fixture.
