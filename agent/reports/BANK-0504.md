`scripts/test/loan-scoring-maker-checker-e2e.ps1`: the maker creates the review,
self-approval is rejected with HTTP 409, and an independent `LOAN_APPROVER`

with a reason; the checker must be a different subject, supply the current
version and a reason, or the operation returns 409/400. No approval endpoint
writes Fineract or disburses funds.
