## 1. 产品视觉定位

- 产品名称：银行业务演示系统（Customer Portal / BANK OPS）。
- 产品类型：面向客户的数字银行门户与面向运营人员的银行运营控制台。
- 使用角色：客户；支付运营人员；审批人员；风险人员；清算、对账、日终与审计人员。
- 主要使用场景：账户与贷款查询、转账、收款人管理、文档/消息查询；支付监控、风险处理、Maker-Checker 审批、清算、对账、日终、审计与系统健康查看。
- 视觉关键词：金融秩序、克制、权威、精密、可审计、低干扰、层级清晰。
- 专业感关键词：深墨黑结构线、华兴红行动焦点、纯白数据平面、细金属灰分割线、强对比数字排版。
- 禁止风格：游戏化、糖果色、蓝紫渐变、玻璃拟态、夸张圆角、营销 Banner、插画堆叠、霓虹发光、过多胶囊标签。
- 推荐模式：默认浅色；运营控制台保留深黑左侧导航，不使用全页面深色模式。
- 信息密度：客户门户中等密度；运营控制台中高密度，优先表格、时间线和描述列表。
- 参考产品类型：严肃商业银行网银、清算运营台、审计与合规控制台。

### 2.2 字体与字号

- 中文字体：`PingFang SC, Microsoft YaHei, Noto Sans SC, sans-serif`。
- 英文/数字字体：`Inter, Arial, sans-serif`；金额、ID、时间使用等宽数字特性。
- 页面标题：28px / 700 / 38px；运营台 26px / 700 / 36px。
- 区块标题：18px / 650 / 28px；表格工具栏标题 16px / 650 / 24px。
- 正文：14px / 400 / 22px；辅助说明 12px / 400 / 18px。
- 表格：13px / 400 / 20px；表头 12px / 650 / 18px。
- 代码、ID、哈希与 Trace：12px / 500 / 18px，等宽字体。

### 2.3 间距与尺寸

- 顶部导航：64px，高度固定；客户门户使用白底黑字红色当前项。
- 左侧导航：运营台 240px 展开、72px 收起；黑底，不新增导航项。
- 右侧详情栏：仅已有“详情”交互页面使用 360px 抽屉；当前没有常驻详情栏。
- 内容最大宽度：客户门户 1200px；运营台占满减去侧栏后的内容区。
- 页面边距：桌面 32px；卡片间距 16px；卡片内边距 24px；表格行高 52px。
- 按钮/输入框高度：40px；高风险确认按钮 40px，不用超大红色块。
- 圆角：卡片 8px、输入与按钮 6px、状态标签 4px；禁止 16px 以上的“大圆角”。
- 阴影：仅浮层 `0 8px 24px rgba(21,21,21,.14)`；普通卡片不使用悬浮大阴影。
- 边框：1px `#D9D9D6`；当前页/高风险区域可使用 2px 语义色左边线。

### 2.4 图标与状态标签

- 图标：18px 线性图标，1.75px 描边；运营侧栏 20px；禁用和次级图标使用 `#6B6B68`。
- 风险/审计图标：使用盾牌、放大镜、链路、账本、时钟、警示三角等明确隐喻；不使用表情符号。
- 统一状态标签：高度 22px，4px 圆角，文字 12px/650；采用浅色背景、同色边框、深色文字。

## 3. 全局页面框架

### 客户门户 `/portal/*`

```text
┌──────────── 64px 顶部：银行标识 / 现有路由导航 / 客户入口 ────────────┐
├──── 主内容（最大 1200px，白色业务卡片 + 暖白底）───────────────────────┤
```

## 6. 页面完整设计规格

所有页面共用以下状态规则：加载使用现有 Skeleton/Loading 容器；空态使用白底、细灰边线、简洁文字和返回/主操作；网络错误使用失败红左边线 Alert 与“重试”按钮；无权限状态当前无页面模型，统一标记 `TBD-NEED-CONFIRMATION`。除现有审批、清算、对账、日终触发操作外，不新增二次确认。

## 9. 统一风格转换规则

1. 不改动页面标题、字段名称、表格列、状态枚举、按钮语义、现有接口或路由。
2. 所有客户页面从默认 Ant Design 观感转换为白色内容面、暖白背景、墨黑文字、深红主操作、细灰边线。
3. 运营侧栏从现有深色风格升级为墨黑底、深红当前项、白色/灰色文字；保留全部原有菜单顺序。
4. 表格优先于卡片；客户资产概览允许账户卡，运营数据优先使用表格、Descriptions 与时间线。
