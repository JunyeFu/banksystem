# BANK-0302 execution report

Status: DONE

The processor now maps a Fineract domain rejection (for example insufficient
funds) to channel `FAILED`, persists a bounded `failure_reason`, and emits a
failed status outbox event. An authorized USD 999,999,999 test transfer returned
`PROCESS=FAILED` and the channel row was `FAILED`; the temporary order and
identity were removed without a core transaction.

Transfer creation now writes the business row and `transfer_outbox` event in the
same channel transaction. Replay of an idempotency key returns before a second
outbox event can be inserted. Transfer state reads are exposed through the
operations contract, and the channel database includes a unique consumer/event
Inbox table with an atomic claim service for duplicate event suppression.
