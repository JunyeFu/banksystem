# BANK-0606 P1 transfer-contract remediation

## Scope and ownership

- BankingDomainAgent: transfer state machine, processor, clearing bridge, EOD and Liquibase migration.
- OperationsFrontendAgent: operations status type contract.
- TestabilityAgent: state-machine contract tests and Test Support assertions/time-travel changes already present in this P1 worktree.

## Change

The canonical transfer state set is now `CREATED`, `RISK_PENDING`,
`REVIEW_REQUIRED`, `APPROVED`, `RESERVED`, `SUBMITTED`, `SETTLED`, `FAILED`,
`TIMED_OUT`, `RETURNED`, `REVERSAL_PENDING`, and `REVERSED`.  The v2 Liquibase
changeset maps only legacy status values in `transfer` and
`transfer_state_history`; it does not modify amounts, balances, or core data.

## Verification and rollback

- Operations console production build passes.
- Backend test execution requires JDK 21. The host wrapper found an older JDK,
  so its compiler rejected release 21; execute the Maven test suite in the
  documented JDK 21/container environment before deploying the changeset.
- Roll back application code by reverting this change. Do not roll back the
  status migration by direct database edits; use a reviewed forward Liquibase
  changeset if rollback is required after deployment.
