# BANK-0201 execution report

Status: REVIEW

Implemented a Java 21 Spring Boot Fineract adapter in
`services/bank-channel`. The adapter centralizes the Fineract base URL, tenant
header, and Basic credentials, exposes only linked customer account reads, and
maps core adapter failures to RFC 9457 Problem Details. The channel service uses
PostgreSQL for its channel-owned schema and requires authenticated customer JWTs
for customer routes.

The image is built from digest-pinned Maven and Java runtime images. The local
read-only Fineract integration probe is `scripts/test/local-fineract-adapter.ps1`.
