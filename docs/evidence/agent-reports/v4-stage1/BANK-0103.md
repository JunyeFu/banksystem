# BANK-0103 execution report

Status: REVIEW

Added fixed-version Keycloak 26.3.3 with separate customer and internal realms.
The customer public client uses Authorization Code with PKCE S256 and the
internal service client is isolated in a separate realm. Admin credentials are
required through local environment variables and are not present in committed
files.

The service is loopback-only at `127.0.0.1:18082`; no database or broker port is
exposed. Realm import is automatic for a fresh channel deployment.
