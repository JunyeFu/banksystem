# Phase 0 baseline evidence

This baseline is the banking target-system baseline for the external-demo product. It must remain reproducible and portable to the later intranet deployment.

This directory contains read-only runtime discovery, exported local API contracts,
and security audit evidence. Values that could disclose credentials or customer
data must be redacted.
