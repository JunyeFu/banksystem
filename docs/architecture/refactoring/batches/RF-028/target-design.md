# RF-028 Target Design

The product is managed as large A packages, medium single-axis RF capability packages and small 1-3 day executable packages. A small package is executable only when its slice and command-level task both exist. UI small packages additionally require their referenced `VQ-xx` textual owner decision.

The hierarchy file defines refinement, business rules, pitfalls and implementation templates only. It cannot change task status or implementation order. AI images confirm information hierarchy and visual intent; OpenAPI, explicit page states, tests and browser evidence remain the executable contract.
