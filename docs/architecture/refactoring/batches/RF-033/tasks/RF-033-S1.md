# RF-033-S1：客户页面真实转账闭环

## 业务目标

客户在已确认的页面风格中创建转账、显式确认，并只在 Fineract 结算完成后看到成功结果。

## 输入与输出

输入为合成客户、账户、收款人和 `100.00 CNY`；输出为状态、转账参考号、业务关联号、核心参考号和回单动作。

## 实现

创建时发送独立幂等键和关联号；验证按钮调用确认 API；成功响应后进入结果页；失败保持当前页并显示明确错误。

## 项目易错点

不得把页面跳转当成确认，不得在创建响应后显示结算成功，不得在浏览器或证据中记录登录凭据。

## 验证

STATIC：Customer Portal build。INTEGRATION/BROWSER：Fresh 合成拓扑中的 create-confirm-result 与截图。

## 完成门

浏览器只产生一笔入账；页面、Channel 与 Fineract 状态一致；截图继承 VQ-03 视觉层级；证据可校验。

已完成：Fresh Chromium 登录、创建、显式确认和结果回读通过；一次创建、一次确认、一次入账，页面/账本/Fineract 状态一致。
