# RF-025-S1 v4 Ledger Task

Implemented the independent CLI Agent v4 ledger in a temporary-root-first slice. Business rule: 18 means the Cartesian product of nine governed cases and two governed variants under one bound identity. Common failures blocked by the implementation: counting retries, importing v3 records, overwriting terminal evidence, storing undeclared/raw inputs, admitting an unbound source identity, or accepting a cross-identity public readback. Implementation shape: schema and key normalization → immutable append → current same-identity projection → historical retention → safe checkpoint → isolated tests.
