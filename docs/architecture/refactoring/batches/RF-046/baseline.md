# RF-046 Baseline

RF-045 proves one real browser execution and verifies the stored report, log and screenshot outside the product CLI. The formal Worker does not capture a DOM snapshot, Playwright trace or bounded network record. The existing `evidence <journeyId>` command projects metadata but does not require the complete evidence set or ask Harness to re-read and hash stored bytes.
