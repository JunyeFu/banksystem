# RF-015 Target Design

One normative CLI Agent baseline owns product and architecture decisions. One YAML portfolio owns TP00-TP10 dependency metadata. Each task package owns business rules, common failure modes, implementation shape, scope and completion predicate. `agent/backlog.yaml` remains status authority and `v54-implementation-batches.md` remains order/authorization authority.

Only TP00 is closed as governance work. TP01-TP10 remain blocked until a dedicated single-axis RF batch, slice and command-level task exist.
