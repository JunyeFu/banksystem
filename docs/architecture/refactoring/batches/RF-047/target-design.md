# RF-047 target-design

CLI completion is a candidate outcome, not acceptance. The L1 driver invokes public evidence verify; Harness must return terminal Journey, PASSED Run, SUCCEEDED Task, exact identity and five verified artifact kinds. Input file and image digests plus the expected evidence predicate bind each checkpoint. Old identities cannot return ALREADY_PASSED.
