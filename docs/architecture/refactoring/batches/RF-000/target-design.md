# RF-000目标设计

RF-000建立四个相互校验的控制面：全过程规范、模块/依赖登记、批次合同Schema、自动校验器。事实资产进入 `docs/current-state/`，稳定规则进入 `docs/architecture/refactoring/`，批次状态进入本目录；项目实施顺序和任务状态仍分别由既有唯一权威文件控制。

RF-000不改变业务模块、运行时、数据库、端口、Agentflow或发布制品。
