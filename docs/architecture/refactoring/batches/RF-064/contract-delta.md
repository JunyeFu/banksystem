# 合同增量

银行公开API不变。S2先核对现有CLI/MCP/Harness调度和接管接口，存在则复用。S3补反馈经验合同必须覆盖适配器/版本/反馈来源/候选验证，新增字段先写消费者和生产者反例；Quality不增加写接口。机构验证码未给类型时合成接口验证与真实接管明确分开。
