# RF063-S3：模块依赖与查询归属

## 业务目标
Controller无查询语法、风险支付运营依赖环消除。

## 输入与输出
当前工作区源码及既有合同；覆盖问题 M10,M16及宏观依赖环。输出可检验修复及证据。

## 实现
建立最小失败反例，沿生产调用链修复，删除失效逻辑。路径白名单：services/bank-channel-service, docs/architecture/refactoring/module-boundaries-v1.yaml。控制文件和证据索引允许同片回灌。

## 项目易错点
保留用户脏工作区；远程成功不等于本地完成；现有证据只证明对应源码和运行身份。

## 验证
Java21 mvnw.cmd test; static module dependency analysis；失败保留原因，修复后重跑受影响门。

## 完成门
Controller无查询语法、风险支付运营依赖环消除，相关命令退出0且复审未发现本项残留；运行/压力未执行时保持未完成。
