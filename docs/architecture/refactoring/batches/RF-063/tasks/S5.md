# RF063-S5：统一验收及独立复审

## 业务目标
逐项复审、真实黄金链、压力性能及当前身份结果明确。

## 输入与输出
当前工作区源码及既有合同；覆盖问题 M17及可用性。输出可检验修复及证据。

## 实现
建立最小失败反例，沿生产调用链修复，删除失效逻辑。路径白名单：demo.ps1, scripts/test, scripts/demo, docs/current-state, infra/gateway/nginx.conf。控制文件和证据索引允许同片回灌。

已观察部署故障：定向替换两个 Channel 容器后，Gateway 的静态 upstream 未刷新 IP，黄金链在 fixtures:seed 返回404。服务直连可达，现用 Nginx 为1.27.5。增加 Docker DNS resolver 与共享 zone/resolve，先 nginx -t，再无停机 reload，再从黄金链起点重测；不改认证、不重启整个拓扑。

## 项目易错点
保留用户脏工作区；远程成功不等于本地完成；现有证据只证明对应源码和运行身份。

## 验证

1. 将rf057-report与demo verify接入S4认证内部验证器；缺证据/NO_GO退出5，只有验证器GO退出0。失败生产者仍封存真实报告与清理结果。
2. 在RF-057正式清单完成后逆向复审M01—M17并回填当前状态；源码门完成不等于28项完成，不与RF-057形成循环入口依赖。
3. 分开本地验证、远端CI、候选隔离复现与人工验收；未执行项保留未完成。原服务和卷保持，不自动发布。

demo.ps1 status; demo.ps1 verify; RF057 current acceptance; docs validation；失败保留原因，修复后重跑受影响门。

## 完成门
逐项复审、真实黄金链、压力性能及当前身份结果明确，相关命令退出0且复审未发现本项残留；运行/压力未执行时保持未完成。
