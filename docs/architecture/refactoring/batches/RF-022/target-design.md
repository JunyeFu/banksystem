# RF-022 Target Design

Define a normal CLI profile with Node24 interactive entry plus Harness, independent MCP and Worker managed services. A pure lifecycle planner fails write readiness when any Flowise marker or port owner exists. Legacy Flowise lifecycle is referenced only by a disabled cold-rollback descriptor with a distinct authorization variable. ReleaseIdentity v4 aggregates CLI/TUI, Controller v2, MCP, Harness, Worker, contracts, exact locks, runtime manifest and lifecycle sources without reading secrets or user data.
