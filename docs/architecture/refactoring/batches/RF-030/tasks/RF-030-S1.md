# RF-030-S1：幂等 Fineract 合成种子

## 业务目标

演示环境重复播种客户甲、客户乙及其储蓄账户时，Fineract 中只有一组业务实体；新账户经正式命令激活并获得合同规定的初始余额。

## 输入与输出

输入为受控 fixture 合同、Fineract API 和本地 Test Support 权限。输出包含稳定逻辑引用、Fineract 客户/账户 ID、币种和 `CREATED` 或 `REUSED` 动作，不输出完整账号或凭据。

## 实现

为客户与账户声明稳定 external ID；先按 external ID 查询，缺失时才创建。只对新账户执行 approve、activate 和初始入金，任何命令失败直接失败。

## 项目易错点

不得以 Channel 数据库记录代替 Fineract 查询，不得吞掉账户生命周期失败，不得在每次调用中生成随机客户身份。

## 验证

运行 Bank Channel 单元测试、RF-030 治理校验、文档校验和 `git diff --check`。运行集成门时对同一环境连续调用两次 seed，第二次必须全部 `REUSED` 且实体 ID 相同。

## 完成门

46 个单元测试及隔离 INTEGRATION 已通过；连续与重启后播种均为 `REUSED`，两个账户的 CNY 初始余额精确匹配 fixture。实现改变正式测试合同，后续冻结候选身份时必须纳入新 ReleaseIdentity。
