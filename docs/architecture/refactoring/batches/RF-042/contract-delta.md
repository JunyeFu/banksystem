# RF-042 Contract Delta

The model check consumes exactly the three HENGZHUN model variables. A successful result contains `status`, `modelName`, `baseUrlHash`, `providerProtocol`, and `endpointKind`; failure contains a stable code and the same non-secret binding fields when available.
