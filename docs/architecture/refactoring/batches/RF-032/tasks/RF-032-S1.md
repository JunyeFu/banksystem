# RF-032-S1：客户确认命令

## 业务目标

客户只可确认自己的已创建转账，确认后由 Channel 通过 Fineract 入账并回读完整结果。

## 输入与输出

输入为客户 JWT 和 transfer ID；输出为现有 Transfer 读模型。

## 实现

新增 subject-scoped confirm 接口，显式调用幂等 Processor 并回读结果。

## 项目易错点

不得让客户调用 internal 端点，不得确认他人转账，不得加入后台隐藏重试。

## 验证

Java 单元测试及 OpenAPI 解析。

## 完成门

本人确认结算、终态重放不重复入账、他人访问为 404。

已完成：单元合同验证本人/他人边界；Fresh 集成通过客户确认端点完成一次入账，终态重放未再次改变余额。
