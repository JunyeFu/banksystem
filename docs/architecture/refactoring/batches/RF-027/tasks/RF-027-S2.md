# RF-027-S2：根生命周期与本地配置

## 业务目标

Windows 11 用户只通过仓库根目录 `demo.ps1` 准备、启动、查看和停止银行演示系统与独立 CLI Agent 服务；默认停止保留数据，数据重置只能由独立 `reset` 命令触发。

## 输入与输出

- 输入：Windows PowerShell、Docker Desktop、Node、Java、`.env.example`，以及唯一模型配置 `HENGZHUN_MODEL_NAME`、`HENGZHUN_MODEL_BASE_URL`、`HENGZHUN_MODEL_API_KEY`。
- 输出：本地 `.env`、Docker secret、Harness 本地服务令牌、三个前端镜像、银行 Compose 服务、Harness/MCP/Worker 状态和脱敏状态摘要。
- 公共入口：`.\demo.ps1 prepare|up|status|down|reset`。
- 退出码：`0` 成功，`2` 命令或配置错误，`3` 依赖或服务未就绪，其他底层失败保持非零并停止。

## 实现

1. 先以公共脚本入口建立会失败的生命周期合同测试。
2. `prepare` 检查必需工具，拒绝占位模型配置，生成或保留本地秘密，准备独立 Agent 运行时并构建固定镜像。
3. `up` 先启动 Fineract Compose，再启动 Channel Compose，最后调用现有 `NORMAL_CLI` Agent 生命周期；不调用 I9/I10 Flowise 生命周期。
4. `status` 输出银行服务、访问地址、ReleaseIdentity、模型绑定和 Harness/MCP/Worker 状态，不输出秘密。
5. `down` 只停止现有 Agent 管理进程与两个项目 Compose，保留卷；`reset` 在同一明确命令中移除项目卷和 Agent 本地运行数据。

## 允许与禁止路径

- 允许：`demo.ps1`、`.env.example`、`scripts/deploy/**`、RF-027 与 A02 治理文件。
- 禁止：`apps/**`、`services/**`、`platform/hengzhun-regression-system/**`、合同、数据库迁移和业务 Compose 内容。

## 必须保持

- Fineract 是唯一账务权威；本任务不播种业务数据。
- Harness SQLite 是唯一测试状态权威。
- Flowise 不启动、不依赖、不回退。
- `down` 不删除命名卷；脚本不停止未知进程。
- 浏览器访问地址和银行 API 保持不变。

## 修改预算

S2 最多新增 4 个文件、修改 12 个文件、净变更 900 行；不增加依赖、迁移或业务合同。
