# Controller transport and contracts

## 业务目标

Controller transport and contracts; one vertical slice, estimated 1-3 development days. State is maintained only in agent/backlog.yaml.

## 输入与输出

Input: approved Figma v2 and the source facts in baseline.md. Output: this slice's contract/code and independently classified evidence; no retrospective PASS.

## 实现

Trace start/continue/NEEDS_INPUT/cancel semantics before changing them. Define a same-origin loopback transport that delegates to createProductionService; no browser service token and no raw checkpoint or reasoning response. Freeze the OpenAPI contract and generated client shape; write endpoint boundary tests after source analysis.

Concrete steps: (1) characterize the existing production-service with isolated test stores/MCP/model doubles; (2) define Zod boundary schemas and derive the sole OpenAPI artifact from them; (3) implement the HTTP router without starting a listener or introducing an execution/state implementation; (4) check generated contract drift, HTTP producer/consumer agreement and existing CLI behavior. RF067 supplies persistence; RF066-S2 composes the router with the real production service. A factory tested in isolation is not a running workbench.

Observed source constraints: direct start returns NEEDS_INPUT before decision/execution; continueSession forks a checkpoint while retaining the Journey and currently enters the Controller path; aborting MCP waiting is not a Worker cancellation or a funds rollback. S2 must preserve Journey input continuity and explicitly report uncertain execution after interruption. No fresh Journey is silently substituted for missing-input continuation.

Allowed paths: `contracts/openapi/agent-workbench-api.yaml`, `platform/hengzhun-regression-system/agent-cli`, `platform/hengzhun-regression-system/scripts/verification`, `scripts/test/verify-agent-workbench.ps1`. Forbidden: banking services/core data/Keycloak/Flowise, unrelated dirty work and broad process/container actions. Open at most two implementation modules at once; complete producer/consumer changes sequentially.
