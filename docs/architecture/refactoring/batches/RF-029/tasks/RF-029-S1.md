# RF-029-S1：独立 Agent 浏览器运行时

## 业务目标

新克隆中的 CLI Agent 可以从它自己的受控运行时加载 Playwright 和 Midscene，并安装与冻结文件一致的 Chromium；它不读取、启动或借用 Flowise 的依赖树。

## 输入与输出

- 输入：已冻结的 `config/demo-runtime-freeze.json`，受控 Node 20 运行时和 npm registry。
- 输出：受版本控制的 `runtime/package.json` 和 lockfile，以及忽略的本地 `runtime/node_modules` 与固定 Chromium。
- 公共入口：`demo.ps1 prepare`；安装失败返回非零且停止。

## 实现

1. 运行时清单只声明冻结的 `playwright`、`@midscene/web` 与 `@midscene/cli` 精确版本。
2. `prepare` 用 Agent 的 Node 20/npm 在 `runtime` 中执行锁文件安装，并执行该版本 Playwright 的 Chromium 安装。
3. 验证 Worker 的 `runtime/node_modules` 解析同时得到 Playwright、Midscene 与冻结 Chromium；不增加备用包、重试或 Flowise 路径。

## 项目易错点

- Worker 的相对 `runtime/node_modules` 路径是现有正式执行边界；根 `node_modules` 和 Flowise 都不是替代来源。
- `demo-runtime-freeze.json` 的 1.59.1/1.10.5/Chromium 1217 是已观察到的运行时合同；不得以安装时最新版本替换。
- 浏览器是本地生成物，不能作为 Git 大文件提交。

## 完成门

安装清单、锁文件、解析路径和浏览器 revision 与冻结合同一致，且所有验证命令通过。此任务不提供 BYOK、银行、LIVE_E2E、Full18 或发布结论。
