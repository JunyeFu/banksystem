# RF-019 Baseline

RF-018 is CLOSED. Controller v2 still uses `MemorySaver`; proposal arguments and security bindings are process-local, so an approval cannot survive restart. There is no session schema, encrypted payload, safe index, retention or fork/archive contract. Formal `.data` remains out of scope and untouched.
