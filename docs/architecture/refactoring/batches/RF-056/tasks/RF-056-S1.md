# RF-056 S1: Audience-bound PKCE session

## Business goal
Customers and staff can sign in to their own bank APIs, and a customer reload keeps the Keycloak-backed session without a password token request.

## Input and output
Existing Keycloak realms, Bank Channel decoder and customer portal. Output is a real audience-bearing token and authorized page readback; never record raw tokens.

## Implementation
Add audience issuance to imported realms and retained-realm provisioning; inspect token claims before switching the decoder. Validate issuer, audience and realm-specific authorized party. Remove customer password grant and password UI; on reload start PKCE authorization against the retained Keycloak session.

## Project pitfalls
Retained realms do not reimport JSON; prior service tokens have no audience until re-provisioned. Agent source identity is already stale and cannot be reused.

## Done
- `services/bank-channel-service/mvnw.cmd test` exits 0 with negative aud/azp tests returning 401.
- `npm.cmd --prefix apps/customer-portal run build` and `npm.cmd --prefix apps/operations-console run build` exit 0.
- `scripts/demo/verify-fixed-demo-identities.ps1` exits 0 with real Keycloak login and customer reload.
- `pwsh -File scripts/demo/verify-bank-token-boundary.ps1` exits 0 after real signed wrong-audience and wrong-azp tokens both receive HTTP 401 despite `CUSTOMER` role.
- Record claim names, result and no raw token in `evidence-index.md`; S2 remains blocked until these pass.

## Result

Java 21 Maven tests and both portal builds exited 0. Retained Keycloak client provisioning disabled customer direct grant and issued the configured audience for customer, operations and service clients. A real browser verified both user tokens and both portals' reload through Keycloak PKCE. The rebuilt Bank Channel and Test Support images remained healthy; Test Support isolation passed after server-side validation was enabled. The signed negative-token probe returned `RF056_TOKEN_BOUNDARY=PASS wrongAudience=401 wrongAzp=401 correctRole=PRESENT` and removed its temporary client.
