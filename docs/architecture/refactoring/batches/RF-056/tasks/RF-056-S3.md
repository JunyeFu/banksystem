# RF-056 S3: Five Fineract capability ports

## Business goal
Bank use cases depend on the core capability they need, with Fineract still the only banking truth source.

## Input and output
Existing adapter methods and Fineract REST contracts; output is Customer, Account, Transfer, Loan and Core Operations ports with business types and one HTTP transport.

## Implementation
Migrate callers by capability, preserve transfer idempotency and unknown-result behavior, replace mixed HTTP implementations, delete old adapter after last caller.

### S3-1: Account boundary
- Paths: `services/bank-channel-service/src/main/java/local/bank/channel/FineractAccountPort.java`, account/identity/notifications/payments/beneficiaries callers, `TestSupportController.java`, `FixtureLifecycleService.java`, matching tests in `src/test`.
- Return named account, transaction, cashier, and command results; parse Fineract aliases, currency, balance, and status in the port. The customer, statement, transfer ownership, and Test Support paths consume typed fields only.
- Done: no account-port public `Map` return; account ownership, statement balance, fixture seed, and transfer tests pass.

### S3-2: Loan and operations boundary
- Paths: `services/bank-channel-service/src/main/java/local/bank/channel/FineractLoanPort.java`, `FineractOperationsPort.java`, customerprofile/identity/audit/payments callers, `TestSupportController.java`, matching tests in `src/test`.
- Return named loan, command, and journal results. Move Fineract loan request construction into the loan port. Job/date writes with unused bodies return no payload. Preserve the observed public `core` JSON through an opaque edge-only payload; business callers may not inspect it.
- Done: no loan/operations-port public `Map` return; existing loan JSON snapshots, EOD step handling, and journal assertions pass.

### S3-3: Contract and runtime closure
- Paths: `services/bank-channel-service/src/test`, the five Fineract ports and transport, `docs/architecture/refactoring/batches/RF-056`, `agent/backlog.yaml`, `agent/plans/active/v54-implementation-batches.md`.
- Add local HTTP contract cases for paths, headers, 404 lookups, account readback, loan commands, and transfer definitive/unknown outcomes. Run Java 21 and governance/docs validation, then replace only Bank Channel and Test Support images and rerun the real golden journey.
- Done: port return signatures contain no `Map` or `List<Map>`; golden transfer conserves balances with Fineract and operations readback; evidence is recorded before S3 is closed.

## Project pitfalls
The existing adapter has 15 callers and transfer's uncertainty semantics are money-critical; do not turn a timeout into a blind retry.
