# RF-054 decision log

- Loan creation is a draft operation; the portal explicitly submits the returned version.
- Repayment methods are limited to equal-installment and equal-principal codes.
- Only one pending approval may exist for an application, and the maker cannot check it.
- Core-submit remains a LOAN_OFFICER action after independent approval.
- Customer-supplied storage references are removed; references are generated by Bank Channel.
- A synthetic Fineract loan product was created through the official API for live verification. RF-055 owns making this product part of the repeatable fixture source.
