# RF-041 Contract Delta

The formal session grammar becomes `hz-agent session start`, `hz-agent session resume <sessionId>`, and `hz-agent session status <sessionId>`. Resume and status are read-only Harness projections; start creates one minimal Harness Journey through MCP.
