# RF-031-S2：幂等 Fineract 入账

## 业务目标

已接收的内部转账只通过 Fineract 正式 API 入账一次，重复处理不重复改变余额。

## 输入与输出

输入为 Channel transfer order；输出为 Fineract transaction reference 和终态，失败输出明确 FAILED。

## 实现

使用显式当前交易日期和由外部幂等键派生的核心幂等键调用 Fineract；终态再次处理只回读，不再调用核心。

## 项目易错点

Fresh Fineract 不一定存在可读取的 business-date 记录；核心成功后 Channel 写入失败时只能依靠相同核心幂等键重放，禁止生成新键。

## 验证

执行 adapter/processor 单元测试和 Fresh Fineract 集成；对同一 transfer 处理两次并核对核心只产生一笔。

## 完成门

正式 Fresh 集成已获得非空 Fineract transaction reference，重复处理余额不再变化；额外恢复活动证明核心成功而 Channel 回滚后，相同核心幂等键不会二次入账。
