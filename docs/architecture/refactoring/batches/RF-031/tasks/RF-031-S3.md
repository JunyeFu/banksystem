# RF-031-S3：余额守恒与关联证明

## 业务目标

100.00 CNY 转账后，付款账户减少 100.00、收款账户增加 100.00，Channel 投影借贷相等且使用同一业务关联号。

## 输入与输出

输入为转账前后 Fineract 账户摘要及 transfer order；输出为余额差、核心引用、两条 ledger projection 和 correlation 连续性证据。

## 实现

Processor 从 `transfer_order.correlation_id` 写入一借一贷，收据和读模型回读同一 Fineract core reference。

## 项目易错点

Channel ledger 是证据投影而非账务真相；不能用它替代 Fineract 余额，也不能把 idempotency key 写成 correlation ID。

## 验证

执行 processor 单元测试；集成前后分别读取 Fineract 余额并验证两账户差额及总额守恒。

## 完成门

正式 Fresh 集成已证明借方等于贷方，两个余额变化与 100.00 CNY 完全一致，客户/运营/ledger 的 correlation ID 和 core reference 连续一致。
