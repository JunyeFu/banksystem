# RF-031-S1：转账与关联合同

## 业务目标

每次转账明确携带独立的幂等键与业务关联号，客户和运营查询都能回读同一关联号。

## 输入与输出

输入为合法 JWT、`Idempotency-Key`、`X-Correlation-Id`、账户、CNY 金额和业务备注；输出为 202 接收结果及稳定 transfer ID、金额、币种和 correlation ID。

## 实现

两个写入口共同校验必填关联头；幂等键只控制重复提交，correlation ID 只贯穿业务证据，不互相替代。

## 项目易错点

不得从 MDC 隐式补造业务关联号，不得把 BigDecimal 输出为浮点数，不得让重复幂等键承载不同请求体。

## 验证

执行控制器单元测试、Customer/Operations OpenAPI 解析与 RF-031 治理校验。

## 完成门

缺失或非法 correlation ID 返回明确 400；正式 Fresh 集成中相同幂等键与相同请求返回同一 transfer ID，合同语义门已通过。
