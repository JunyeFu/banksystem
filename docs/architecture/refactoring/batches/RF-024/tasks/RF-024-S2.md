# RF-024-S2 L1 LIVE Task

After exact new LIVE authorization, bind the configured model into v4, manage only Harness/MCP/Worker, prove public readback, run `TEXT_ONLY` and then `TEXT_WITH_IMAGE` on one identity, and stop immediately on the first deterministic failure. No Flowise start, publication, shadow retry or evidence reuse is permitted.

Offline preparation is implemented. `run` may stop at an exact approval checkpoint and returns the safe `sessionId + proposalId + contentHash` tuple; `approve` or `reject` must repeat that tuple. The same-identity checkpoint advances to `TEXT_WITH_IMAGE` only after `TEXT_ONLY` reaches `COMPLETED`. This preparation does not authorize or prove a LIVE execution.
