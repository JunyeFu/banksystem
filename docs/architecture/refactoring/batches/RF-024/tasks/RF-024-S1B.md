# RF-024-S1B Production TUI and Bounded Evidence Task

Connect all interactive CLI entry modes to the production service without duplicating Controller business state. Follow-up input must fork a new DPAPI-encrypted session/thread on the same authoritative Journey, reject attachment carryover and stop before an unresolved exact approval. The evidence command must remain a pure `journey_get` read with bounded metadata and no download grant. Completion requires focused offline tests and a real PTY start/exit smoke; it does not authorize a service, model, browser or LIVE run.
