# RF-024-S1C Typed Credential Enrollment Operation

Bind the baseline `hz-agent credential enroll` and TUI `/credential` commands without inventing a Journey. The first command creates a dedicated DPAPI-encrypted `CREDENTIAL_ENROLLMENT` operation and returns one HIGH exact proposal with no MCP call. `resume <operation-id> --approve --proposal <id>` may invoke `credential_session_create` exactly once, then pass its validated loopback capture URL only to the local browser launcher. Persisted state and JSONL must never contain the capture URL/token or credential plaintext. Rejection, replay, hash mismatch, expiry, cross-release restore and browser-launch failure fail closed without duplicating the mutation.

Machine predicate: Node 24 offline integration proves zero calls before approval, exactly one write after DPAPI-store restart, no forbidden bytes in operation files or JSONL, and no second write on replay. This slice is CONTRACT/INTEGRATION evidence only and does not start services or satisfy TP09 LIVE.
