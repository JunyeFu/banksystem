# RF-036 Target Design

An ephemeral synthetic customer authenticates through the real Keycloak password flow. The dashboard reads the linked Fineract account through Gateway, shows exact assets, balance, count, masked number and normalized Chinese status, and retains stable test IDs without changing layout.
