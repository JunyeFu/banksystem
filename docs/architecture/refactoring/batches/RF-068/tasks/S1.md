# RF068-S1：Agent入口与生成客户端

## 业务目标

用户打开独立Agent入口，看到已确认的精简工作台、真实连接状态与空历史；原Quality继续只读。工作量1–2天，状态只查BANKSYSTEM-RF068-S1-FOUNDATION-001。

## 输入与输出

输入：RF066-S2已验收的同源服务及OpenAPI；Figma主屏2:60、空屏2:61、设置2:65。输出：独立构建、生成API类型、同源客户端与统一样式。没有模型时显示配置引导，不捏造可用模型。

## 实现

| 小任务 | 落点与实现模板 | 可观察结果 |

| UI-F01 | 新增`agent.html`、`vite.agent.config.ts`、`src/agent/main.tsx`、`AgentApp.tsx`；base为/agent/，输出dist-agent；不清理原dist | 两个入口独立，刷新会话深链接不404 |

若精确字体缺失，只添加本地字体资产及其许可证，不安装系统字体或第二UI体系。新组件按已有职责拆分，不建立插件框架。允许路径：apps/quality-case-portal/**、scripts/test/verify-agent-workbench.ps1、platform/hengzhun-regression-system/scripts/verification/**及本批文档。禁止在本包修改银行、Keycloak、Harness、Controller或Quality接口。

## 项目易错点

2026-10-21实施细化：沿用原生Figma 2:60/61/65，不重新生图。先交付布局、只读连接状态、可操作的侧栏折叠/设置/重连；历史搜索、新建持久会话、发送、附件和模型选择留给S2–S4，不开放无效按钮。样例历史、用户、模型和READY均不植入；草稿可编辑但本片不提交，刷新深链接只显示入口、不重放。设置仅显示bootstrap实际结果及Quality只读地址。新增本地Noto Sans SC与OFL许可，其他资产复用品牌SVG及Figma图标。

源码已观察到RF066静态服务不接受/agent/assets路径且默认index.html，与本包agent.html产物不一致；先在RF066-S2所属任务补足路径合同和回归，再消费，不在前端绕过base或引入跨源代理。

现有main.tsx的React Query为retry:1，Vite固定/quality/且代理到18443，不能原样复用为Agent接线。静态页面CSP与API响应default-src 'none'须分别配置。Figma示例用户、模型、历史不得作为运行种子。
