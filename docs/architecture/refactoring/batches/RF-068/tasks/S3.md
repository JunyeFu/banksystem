# RF068-S3：真实对话、执行与证据

## 业务目标

用户只在输入框描述目标、补充信息，查看真实过程与结果；失败时得到可处理原因。工作量1–3天，状态只查BANKSYSTEM-RF068-S3-CONVERSATION-001。

## 输入与输出

输入：真实Controller接线、模型绑定、持久历史；Figma运行2:62、失败2:63、完成2:64、证据6:885。输出：ConversationView、Composer、TurnProgress与EvidenceDrawer，消费实际API而非定时演示。

## 实现

| 小任务 | 行为／调用模板 | 可观察结果 |
| --- | --- | --- |
| UI-C01 | 一次提交只生成一个submissionId；发送{submissionId,input,modelProfileId,modelProfileVersion,attachmentRefs}；202后按turnId读回；Enter发送/Shift+Enter换行，中文组合输入期间不发送 | 请求结果未知先读回，不自动换id重试 |
| UI-C02 | GET turn按after/limit/hasMoreEvents补事件，按sequence去重，只轮询选中活跃任务；显示计划摘要和真实工具事件，不显示私有思维链或完整参数 | 无定时假进度，工具返回前不显示成功 |
| UI-C03 | NEEDS_INPUT明确缺失项；补输入提交原任务profileId/version，而非选择器中待用于新任务的模型；后台续接原Journey；完成、失败、中断使用明确结果类别与证据判定 | 回复完成不等于测试通过；缺金额/收款人不发生资金动作 |
| UI-C04 | 运行时发送位变停止；cancel的202只显示STOP_REQUESTED并继续读回；未知结果保留INTERRUPTED及人工介入要求 | 不宣称已撤销或资金已回滚，不静默重跑 |
| UI-C05 | 附件明确限单张PNG/JPEG；用S2冻结的二进制导入合同与安全回执，不接收服务端路径；临时对象URL移除时释放 | 上传失败不提交悬空ref，不展示未接通的PDF/视频/多图能力 |
| UI-C06 | 结果展示真实Journey/Run/Task/ReleaseIdentity；抽屉读证据清单，下载经本地受控代理；无权、缺失、隔离工件显示实际状态 | 不暴露service token、本机路径或虚构余额/通过数 |

允许路径同S1。服务端缺口回归RF066-S2，不在React实现工具调用、SQL或第二个Agent。尚不支持的自然语言意图明确提示能力边界，不谎称已创建计划或已测试。

## 项目易错点

2026-10-22执行细化：保持现有API不变；新任务只消费已登记的默认模型，模型选择/编辑归S4。发送与停止各有同步锁，读取失败停止轮询并允许显式重读；未知提交先GET回读，再允许用户显式用原submissionId核对，不自动生成新提交。历史组件保留分页/阅读位置，实时任务组件独占事件读游标；仅选中会话的当前任务轮询，终态仍排空hasMoreEvents。单图上传/下载使用生成路径与既有CSRF，临时URL在替换/移除/卸载释放。原服务不部署切换，Browser/Conversation使用真实生产HTTP与临时Harness/MCP，模型/执行替身仅在测试进程。

完成谓词：下列Browser/Conversation命令exit0，重复点击/中文输入/丢回执/刷新不产生第二次执行；缺输入续接绑定不变；停止保持未知语义；分页事件、PNG/JPEG及受控下载回执可核验。随后Contract/Integration、既有History/Foundation、双构建与治理/docs通过才登记完成；真实BYOK及原环境联验仍归S5。

现有direct start图片分支只消费第一张，不能把数组合同当多附件已实现。continueSession会派生检查点，并不自动等价于直接执行续接。轮询是读取状态，不是重试模型或业务；无证据COMPLETED只能显示回复完成。

## 验证

STATIC/CONTRACT：前端lint/typecheck/unit、双构建及生成客户端检查。隔离集成覆盖重复提交、丢响应读回、分页、缺输入续接、停止竞态、未知结果、单图与授权证据下载；替身仅限测试进程。

BROWSER：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test/verify-agent-workbench.ps1 -Scope Browser -Case Conversation`覆盖上述状态、中文输入法、键盘、滚动、请求次数及无泄密输出。真实BYOK/银行只读验收不由测试替身替代。

## 完成门

消息到事件/结果/证据连续可追踪；刷新不重复执行，缺输入/失败/停止不伪报通过，附件与证据真实可用；所有可见按钮有动作。无新人工提案审批门、运行时Mock、备用模型或隐藏重试；不自动冻结身份。
