# RF068-S2：历史会话

## 业务目标

用户通过左栏新建、搜索、重开真实对话；刷新不丢失已登记消息，也不重新执行任务。工作量1–2天，状态只查BANKSYSTEM-RF068-S2-HISTORY-001。

## 输入与输出

输入：独立入口、Harness真实历史与分页合同。输出：ConversationSidebar、会话路由和消息页。路径采用/agent/conversations/{conversationId}；conversationId与checkpointSessionId、Journey ID明确分开。

## 实现

2026-10-21执行细化：白名单仅本包文档/控制、apps/quality-case-portal/src/agent（Sidebar、History、已用分页/分组辅助及测试）、main路由、tests/history.browser.cjs、原Foundation回归和共享Browser选择器。API类型继续消费既有生成物，不改合同、Controller/Harness或迁移。列表30/页、正文20/页且服从后台实际游标与输出预算；不提高全局上限。

列表与bootstrap独立读取；NOT_READY不禁止只读历史或空会话登记，403/未取得CSRF时禁止新建。创建只发一次POST，收到id再导航；网络结果未知先要求读取历史核对，不自动重建。查询条件、路由与读取代次绑定，初次读取/翻页/显式重取独立锁定，过期结果丢弃。正文前插按消息id合并，记录渲染前滚动位置并在布局提交后恢复；读取失败保留当前已读正文。路由变化清除未提交草稿，不落浏览器持久层。

浏览器门使用临时Harness SQLite、实际MCP与生产同源HTTP组合；仅在测试进程经Repository/MCP建立合成历史，不播种保留环境，不调用模型/Worker/银行。错误与慢响应仅在隔离浏览器拦截；验证持久会话数、turn数、runs数及派发计数，不用仅页面成功标签作结论。

| 小任务 | 行为／调用模板 | 可观察结果 |
| --- | --- | --- |
| UI-H01 | 新对话调用createAgentConversation({title:'新对话'})一次，收到id再导航；请求中锁按钮；目标未提交前不建Journey | 创建会话不启动测试 |
| UI-H02 | listAgentConversations({q,cursor,limit})；今天/昨天/更早分组；搜索Enter提交，换条件清游标，加载更多消费nextCursor | 空历史、无结果、加载、错误各自明确，无示例记录 |
| UI-H03 | getAgentConversation({conversationId,before,limit})加载最新页；向上补旧页，按messageId去重，前插保留阅读位置 | 正文不截断，页序不乱，不把未加载当无历史 |
| UI-H04 | URL决定选中会话；过期响应不能覆盖新选择；刷新只GET，404显示不存在，错误重取由用户触发 | 刷新/前进后退/切换不发送执行POST，旧身份历史仍可读 |

允许路径同S1。不得把聊天正文、密钥或执行令牌存入localStorage、URL或持久化客户端缓存；确需保留未决提交标识时仅存非秘密ID，不自动重发。API DTO全部生成，不改后台查询语义。

## 项目易错点

CLI sessionList/sessionShow只有安全元数据，不是聊天记录。NEEDS_INPUT后可派生检查点，但侧栏仍是同一conversation。列表状态取自Harness，不靠本地时间或最后一句话猜成功。

## 验证

STATIC/CONTRACT：前端lint、typecheck、unit、双构建及生成客户端漂移检查通过。INTEGRATION：隔离Harness下验证分页、同名会话、namespace隔离；不向保留环境播种假历史。

BROWSER：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test/verify-agent-workbench.ps1 -Scope Browser -Case History`覆盖新建、空/错/无结果、两类分页、快速切换、深链接、刷新、前进后退；以后台执行计数证明刷新/切换增加0次执行。该选择参数待实现。

## 完成门

真实持久历史可完整分页，刷新不重放，错误不清空已读历史。跨后台重启的完整证明在实机验收包完成，不能拿前端缓存冒充持久化。旧身份只读与新任务就绪分开；不冻结身份。
