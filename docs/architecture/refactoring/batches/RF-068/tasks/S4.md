# RF068-S4：模型选择与配置

## 业务目标

用户在输入框下方选择下一新任务模型，在独立配置页维护本地BYOK；当前任务不被切换。工作量1–2天，状态只查BANKSYSTEM-RF068-S4-MODELS-001。

## 输入与输出

输入：真实模型元数据、DPAPI后端；Figma菜单12:1201、配置11:1017、设置2:65。输出：ModelPicker、ModelConfiguration；配置字段仅显示名、model ID、Base URL、API Key。

## 实现

| 小任务 | 行为／调用模板 | 可观察结果 |
| --- | --- | --- |
| UI-M01 | 下方菜单listAgentModels，仅列实际配置；选择作为待提交profileId/version，不暗改服务端默认；缺模型引导配置 | 示例模型不进入运行，更换仅影响下一新任务 |
| UI-M02 | 配置页仅载入安全元数据；密钥不回读，用“已配置，留空保持”占位，不把圆点当新值提交；编辑带version | 明文不进URL、local/sessionStorage、日志、导出或持久缓存；离页清空临时输入 |
| UI-M03 | checkAgentModel只探测当前表单端点；显示检查中/成功/失败安全code，不切模型、不自动重试 | 检查成功、保存成功、执行就绪是不同事实 |
| UI-M04 | create/update成功后显式设置默认；409显示冲突并重载，不自动覆盖；保存成功但默认设置失败分别显示 | 不伪报组合操作全成功；旧任务绑定不可变 |
| UI-M05 | 设置弹层只放连接状态、当前身份、模型配置与只读Quality入口；NEEDS_INPUT续接显示原绑定 | 保存模型不自动获得新身份LIVE权限，也不回退旧模型执行 |

允许路径同S1。银行凭据仍走已有本地登记流程，不进入聊天或模型配置；不新增通用密钥管理后台。配置页采用/agent/models并可返回原会话。

## 项目易错点

### 2026-10-22 执行细化

- 基线：S3 DONE，S4 READY转IN_PROGRESS；main@552b3b8，保留现有脏工作区。仅在上述白名单修改前端、Models浏览器用例、验证入口和本批控制文件，不修改后台合同。
- UI-M01/M05：App统一读取安全模型目录，ModelPicker仅保留内存中的待提交id/version；配置路由记录原会话位置。运行及待输入状态明确显示原绑定，下一选择不改变当前turn。
- UI-M02–M04：ModelConfiguration持有临时表单；创建/版本更新、单端点检查、默认设置分别消费生成客户端。冲突重载安全目录；保存与默认设置分别呈现，离页不保留密钥。
- 验证：合成密钥仅存在隔离测试进程，HTTP→MCP→临时Harness SQLite；检查空密钥保持、409、部分失败、两版本绑定、键盘与1440/390窄屏。复审后再回填证据索引及唯一状态，不启停原服务、不接真实BYOK。

GET只有keyConfigured，没有可编辑的原密钥；profileVersion与任务modelBinding不是一回事。改默认不能改运行/待输入任务。真实密钥输入过程不得录制含请求正文的trace；实机复验使用已有环境绑定与脱敏元数据，密钥写入反例在隔离测试完成。

## 验证

STATIC/CONTRACT：前端lint/typecheck/unit、双构建、生成客户端检查。隔离集成验证不回显/不持久化密钥、留空保持、检查失败、409、保存/设置默认部分失败、两个配置版本不可串用。

BROWSER：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test/verify-agent-workbench.ps1 -Scope Browser -Case Models`检查菜单位置、键盘、配置返回、运行中选择、缺模型与NOT_READY；测试替身不得进入交付构建。

## 完成门

选择、增改、检查、默认设置真实可用，任务绑定可核对；错误透明且无密钥泄漏，符合14px统一文字与布局。真实端点只读验收在实机包完成，不自动冻结身份。
