# RF068-S5：实机接入与独立复审

## 业务目标

原银行服务保持运行，用户通过浏览器真实对话、读历史、选/配模型、查看证据。工作量1–2天，状态只查BANKSYSTEM-RF068-S5-ACCEPTANCE-001；不替代正式28项或整体GO。

## 输入与输出

输入：各级前置证据、托管服务、当前身份与已有授权。输出：Agent URL、实图、操作记录和独立复审结论；不自动发布、提交或推送。
