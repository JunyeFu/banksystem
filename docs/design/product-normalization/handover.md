# 本地候选交付与维护交接

## 接收结论

当前可接收的是受控源码和可审阅的过程资料，尚无通过全部门的最终候选。整体NO_GO，本文不表示接收人已签收，也不承诺生产银行或机构服务器适配。接收者应先阅读[验收现状](acceptance-and-handover.md)，再按[部署说明](delivery.md)选择获准的演示环境。

## 资产与配置

| 资产 | 位置和用途 | 当前交付状态 |
|---|---|---|
| 产品源码与合同 | services、apps、packages、platform及contracts | 本地脏树保留；最终候选提交/构建尚未冻结 |
| 配置和锁 | 版本锁、各package-lock、Compose及示例配置 | 源文件存在；真实密钥只由接收者在本机登记 |
| 规范文书 | 本目录七源稿与documents/catalog.yaml | 源稿可审阅；生成件验页状态见文书目录，最终签收仍待完成 |
| 运行证据 | Harness SQLite、Evidence及对应RF证据索引 | 按来源/身份保留；不将原私有运行目录打包公开 |
| 最终候选包 | 源码、摘要、SBOM、许可、身份和已知限制 | 尚未完成安全/许可、同身份验收和CI，不登记已交付 |
| 面试准备材料 | 外部project-navigation/bank-interview | 与产品分离；默认稿不代表本人贡献或演练已核实 |

接收者使用自己的BYOK和合成测试身份。文书、Git和模型上下文不传递密钥、浏览器Storage State、用户原笔记、真实客户数据或数据库卷。账户密码以本地登记/凭据管理入口交接，不复制到资料包。

## 安装与首次核对

使用Windows 11、Docker Desktop和版本锁中的工具，按根README执行prepare、up、status。确认访问地址、模型绑定和ReleaseIdentity；旧运行服务仍存活不代表源码身份最新。需要真实银行黄金链或Agent测试时，先核任务授权及合成样本所有权，不把资金写入当安装探针。

最终复现必须使用隔离候选环境，不共用保留环境的容器、端口、卷或业务日期。prepare成功、空库启动、黄金转账、verify和停止/重启连续性各有自己的证据；任一步未执行就不勾选复现完成。验证码类型和机构网络/计划任务权限未知时，保留限制，不能通过关闭认证或改用Mock掩盖。

## 日常操作与异常处理

测试维护者描述目标或选择固定脚本，查看执行摘要和证据；负责人查看运行、周期计划和失败接管；本地维护者负责配置、构建与受控恢复。Quality保持只读，产品运行事实只由Harness拥有；外部资料站的自评不改变工程状态。

| 现象 | 首要核对 | 允许的后续动作 |
|---|---|---|
| 模型/依赖未就绪 | 原错误码、配置端点和服务归属 | 明确修正配置或所属服务，不换备用模型/隐藏重试 |
| STALE_SOURCE | 源码、构建、模型和正式清单与绑定身份 | 回到统一候选/身份门，不沿用旧证据冒充当前 |
| 页面失败且可能已提交 | 原业务关联号及Fineract结果 | 核心成功则保留业务成功/测试失败；未知则转人工，不重提 |
| 脚本断言或定位失败 | 原Run、截图、DOM/网络和冻结脚本版本 | 记录人工纠正，独立候选复验；不改业务预期获得通过 |
| 验证码无法处理 | 原挑战/任务及版本 | 原浏览器人工完成再确认，不新建资金请求 |
| 依赖/证据门失败 | 原扫描、工件、身份及验证器失败原因 | 修正实际来源并重新验相应门，不编辑JSON为GO |

保持原服务和数据运行；仅停止或替换已确认属于当前任务的进程/容器。down默认保留卷，reset、恢复出厂、删目录或推进Fineract业务日期均不是常规故障处理。应用回滚与金融补偿不同，任何资金、数据库或核心版本变更遵循专属任务授权。

## 证据与训练交接

维护者须能从目标定位Journey、Run、Task，再定位业务关联号、Fineract交易和证据；截图是页面事实，账务回读是业务事实，两者不能互相代替。案例预期拒绝可以测试通过，A07指定受控失败保留失败Run，非预期失败仍阻断后续正式验收。

培训与演练目前未签收。要求接收者实际完成三角色UAT和七分钟演示，说明真实总账、未知结果和发布验证三个根因案例，并核实个人贡献。资料成稿和模拟问答模板只是练习输入，不是已完成访谈、上岗培训或机构交付。

## 保留与关闭

源码、人工作品、锁、必要输入、原失败和最终证据保持；候选/产物按现有空间规则检查，不擅自永久删除或清理共享缓存。真实保留期、机构安全策略、运维责任人和支持时段尚未确认，不编造承诺。项目关闭仍需最终候选验证、实际接收、遗留事项及责任确认；长期维护与下线不在本轮两周建设完成声明中。
