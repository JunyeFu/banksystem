# 前端页面与状态目录

每个页面至少实现适用的 `loading`、`empty`、`ready`、`error`、`forbidden`、`submitting` 状态。资金、审批和回归执行页面还必须表达业务状态，不得把 HTTP 成功等同于业务完成。

| 业务闭环 | 页面 | 必需业务状态 |
|---|---|---|
| 客户资产 | 登录、概览、账户列表、账户详情 | 登录失败、无账户、无流水、加载失败 |
| 客户转账 | 转账列表、新建转账、结果、回单 | 校验、提交、风险复核、待审批、已结算、失败 |
| 客户贷款 | 列表、申请、详情、文档 | 草稿、提交中、审核中、通过/拒绝、接口失败 |
| 运营支付 | 仪表盘、支付监控、支付详情 | 处理中、风险复核、待审批、清算中、已结算、失败 |
| 审批风险 | 审批队列、审批抽屉、风险告警/案件 | 无权限、冲突、批准/拒绝提交、结果 |
| 账务运营 | 清算、对账、日终、审计、系统健康 | 运行中、成功、差异、失败、恢复 |
| 衡准用例 | 用例、版本、批准、导出（目标） | 草稿、待审核、已批准、冲突、归档 |
| 衡准执行 | 运行、验证、证据、基线、调度（目标） | 排队、运行、暂停、完成、失败、差异、匹配 |

当前不存在的衡准页面保持 `planned`，不得用静态页面冒充已实现功能。
