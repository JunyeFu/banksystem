  观测指标接口

  背景
     HiAgent 平台提供将智能体作为后端服务 API 被业务请求的能力，用户希望获取平台内的
  指标数据作为导出，完成自身的特殊指标的后处理相关的需求。

  调用步骤
1. 第一步：在平台内的密钥管理页面申请自己的 access key 和 secret key。

1. 第二步：使用对应的 sdk 对请求做签名。（具体可以参考 HiAgent 平台 API 调用示例）

  API 接口调用方式（具体可以参考 HiAgent 平台 API 调用示例）X
  获取智能体 token 消耗数量（GetAgentMetricTokenCount）
1. 接口说明：针对智能体相关的 token 消耗的数量

1. 请求 header 说明（适用如下所有接口）：

  1. 请求 header 需要加上 Authorization，参考 HiAgent 平台 API 调用示例利用 sdk 的签名生
       成 Authorization。

  1. 请求 header 需要加上 Content-Type: application/json
