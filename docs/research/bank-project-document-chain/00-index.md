# 银行项目文书链路：RAG 分片索引

> 用途：为“复兴”智能数字银行与“衡准”自动化回归测试平台提供从立项到交付的可检索文书链路。本文及同目录文件是 RAG 的项目文档源；仅使用公开资料，不含真实客户、账户、接口凭据或生产数据。

## 使用边界

- 文书链路是本项目的工程模板，不替代银行真实制度、监管报送要求、法务审核或采购规则。
- 每一份正式文书都必须有版本号、责任人、审批记录、关联需求/变更/测试证据与归档位置。
- RAG 仅可据此产出“草案/清单/缺口提示”；最终发布、上线和验收仍需人工责任人批准。

## 来源层级

1. 监管与行业规则：信息科技风险管理、外包治理、风险评估与报告材料目录。
2. 公开银行采购/招标文件：用于核验实际交付物和附件表单，而非复用其专有内容。
3. 广东华兴银行公开年度报告：仅作为公开信息披露文书的目录、声明、页码和财务表格呈现参考；不复制标识、商标或视觉资产。

## 索引状态

本目录会被 `scripts/rag/build_rag.py` 分类为 `project-document` 并按段落自动拆块。当前 `rag/index/` 存在受保护的未提交修改，因此本次不直接重建索引；待索引工作区清洁或持有人确认后，运行构建脚本即可纳入检索。
