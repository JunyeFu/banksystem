# 1. 系统定位

本系统不是正式测试执行平台，而是：

> **AI Test Authoring System / 大模型辅助测试资产生产系统**

它接收两类输入：

```text
模式 A：测试人员在扣子中输入已实证成功的流程 + 测试页面 URL
模式 B：测试人员在扣子中上传成功操作视频 + 测试页面 URL
```

系统输出：

```text
结构化测试计划
Midscene 复刻轨迹
DOM/ARIA/文本/位置/输入输出/网络事实
Canonical Workflow
Playwright 候选脚本
一轮真实测试结果
候选脚本与证据摘要
```

只有一轮真实 Playwright 测试通过后，扣子才允许向用户输出候选脚本。

# 2. 核心设计思想

## 2.1 扣子模拟 HiAgent

本系统不运行 HiAgent 原始研究代码，而是使用扣子：

```text
Agent
Workflow
Knowledge Base
Variables
Conditional Branch
Tool Call
Loop
Structured Output
```

模拟以下 HiAgent 式机制：

```text
Goal
→ Subgoal
→ Working Memory
→ Observation Summary
→ Next Decision
→ Completion
```

## 2.2 MiMo 替代原 Qwen 视觉模型

调用关系：

```text
Midscene Runtime
→ MiMo V2.5
```

不是：

```text
扣子
→ MiMo
```

MiMo 只负责视觉理解，不负责最终业务决策和正式脚本执行。

## 2.3 主控 LLM 不直接运行脚本

正确链路：

```text
DeepSeek 生成候选代码
→ Tool Request
→ Harness
→ Task Relay
→ Local Bridge
→ Validation Worker
→ Playwright
→ Validation Result
→ DeepSeek
```

“主控 LLM 调用工具测试”是受控工具请求，不是模型直接获得 Shell 或浏览器权限。

# 16. Local Bridge

```ts
export async function pollLoop(): Promise<void> {
  while (!shutdownRequested()) {
    const task = await relay.claimTask({
      workerId: config.workerId,
      supportedTypes: [
        'VIDEO_ANALYZE',
        'MIDSCENE_REPLICATE',
        'SCRIPT_VALIDATE',
        'SCRIPT_CLEAN_REPLAY',
      ],
    });

    if (!task) {
      await delay(2000);
      continue;
    }

    try {
      const result = await dispatcher.execute(task);
      await relay.completeTask(task.id, result);
    } catch (error) {
      await relay.failTask(task.id, normalizeError(error));
    }
  }
}
```

Bridge 只允许出站连接，不开放银行服务公网入口。

## 19.3 复刻

```ts
export async function replay(
  plan: StructuredExecutionPlan,
  browser: Browser,
): Promise<ReplicationTrace> {
  const context = await browser.newContext({
    storageState: await loadTestState(plan.actors),
    viewport: { width: 1440, height: 900 },
    reducedMotion: 'reduce',
  });

  const page = await context.newPage();
  const trace = new ReplicationTraceBuilder(plan);

  try {
    await page.goto(plan.pageUrl);

    for (const step of plan.steps) {
      const before = await capturePageState(page);
      const decision = await midscene.executeStep(page, step, { plan });
      const aligned = await alignVisualDecisionWithDom(page, decision);

      if (!aligned.unique) {
        throw new AmbiguousElementError(step.stepId);
      }

      const after = await capturePageState(page);
      trace.addStep(await buildStepTrace({
        step,
        before,
        after,
        decision,
        aligned,
      }));
    }

    const terminal = await validateTerminalState(
      page,
      plan.successConditions,
    );

    return trace.complete(terminal);
  } finally {
    await context.close();
  }
}
```

```ts
export function scoreCandidate(c: LocatorCandidate): number {
  if (c.matchCount !== 1 || c.visibleCount !== 1) return 0;

  const base = {
    TEST_ID: 100,
    ROLE: 90,
    LABEL: 85,
    PLACEHOLDER: 70,
    TEXT_IN_CONTAINER: 60,
```
