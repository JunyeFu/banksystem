# 10. SSE 实时步骤

```ts
export function useRunEvents(runId: string) {
  const queryClient = useQueryClient();

  useEffect(() => {
    const events = new EventSource(
      `/api/v1/test-runs/${runId}/events`,
      { withCredentials: true },
    );

    events.addEventListener('TEST_STEP_COMPLETED', event => {
      const payload = JSON.parse(event.data) as TestStepEvent;
      queryClient.setQueryData(
        testRunKeys.detail(runId),
        current => mergeRunEvent(current, payload),
      );
    });

    events.onerror = () => {
      events.close();
    };

    return () => events.close();
  }, [runId, queryClient]);
}
```

前端必须支持断线后按 `Last-Event-ID` 恢复。

# 18. Custom Reporter

```ts
export default class PlatformReporter implements Reporter {
  async onTestBegin(test: TestCase): Promise<void> {
    await emit({
      eventType: 'TEST_CASE_STARTED',
      caseCode: test.title,
    });
  }

  async onStepEnd(
    test: TestCase,
    result: TestResult,
    step: TestStep,
  ): Promise<void> {
    await emit({
      eventType: 'TEST_STEP_COMPLETED',
      caseCode: test.title,
      stepName: step.title,
      status: step.error ? 'FAILED' : 'PASSED',
      durationMs: step.duration,
    });
  }

  async onTestEnd(test: TestCase, result: TestResult): Promise<void> {
    await emit({
      eventType: 'TEST_CASE_COMPLETED',
      caseCode: test.title,
      status: result.status,
      attachments: result.attachments.map(a => ({
        name: a.name,
        contentType: a.contentType,
        path: a.path,
      })),
    });
  }
}
```

Reporter 回传失败时，本地必须排队补传，不能篡改测试结果。

# 23. 代码规范

## Frontend

- `strict: true`；
- 页面不直接 `fetch`；
- Query Key 集中管理；
- Zustand 不保存 Server State；
- 权限使用 Route/Action Guard；
- 所有状态有 Loading/Error/Empty；
- 表格查询参数可序列化；
- 大页面按 feature 拆分；
- Evidence Viewer 不内联不可信 HTML；
- Monaco 默认只读。

## Backend

- Controller 不写业务规则；
- 状态机集中；
- 事务位于 Application Service；
- Run 更新使用乐观锁；
- Outbox 和 Run 状态同事务；
- 所有写操作审计；
- 统一 Problem Details；
- 下载证据必须鉴权。

## Worker

- 只执行 Registry；
- `shell:false`；
- 环境变量白名单；
- 临时目录隔离；
- 超时强制终止；
- 退出后清理 Storage State；
- 无核心库写权限。
