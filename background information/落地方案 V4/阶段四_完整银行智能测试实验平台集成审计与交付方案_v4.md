)

  -f compose.yaml `
  -f compose.bank.yaml `

}

# 19. 故障注入

## 19.1 Fineract Down

预期：

- Channel 503；
- 无错误资金提交；
- Test 分类 Dependency Failure；
- 告警触发。

## 19.2 Relay Offline

预期：

- Task Pending；
- Coze 显示本地执行器不可用；
- 不伪造结果。

## 19.3 MiMo Failure

预期：

- Visual Model Failure；
- Midscene 停止；
- 不生成脚本。

## 19.4 Ambiguous Locator

预期：

- 不点击；
- Human Input Required；
- 不坐标兜底。

## 19.5 Dangerous Script

预期：

- Script Rejected；
- 不执行。

## 19.6 Clean Replay Failure

预期：

- 最多修复 3 次；
- 仍失败则不输出脚本。

## 19.7 Asset Tamper

预期：

- Hash Mismatch；
- Test Portal 拒绝导入。

## 19.8 Worker Crash

预期：

- Heartbeat Timeout；
- Run System Error；
- 锁释放；
- 可人工重试。
