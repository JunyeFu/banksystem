工具为什么会重复调用？

工具重复调用的原因有很多，需要针对场景具体分析。但是一般可以通过以下方式来排查：

把模型当成一个小学生，然后来看提示词是否合理，问题是否清晰。作为一个小学生能不能理解你的意思

模型支持的上下文虽然很长，但是不代表只要在这个上下文内，模型的表现都是一样的。这个也很好理解，就和人看书一样，书的内容越多，就越容易看了后面忘了前面。所以一旦工具的输出特别的多，模型的能力就会受到影响，比如模型忘记了之前已经调用过这个工具了。那么它就可能做出重复调用工具的决策。

工具的输出的信息，不足以让模型回答问题，但是工具的名称/描述或是提示词又要求调用这个工具。这也可能导致模型做出错误的决策

Marketplace中的MCP插件如何安装？

Marketplace中的MCP插件分三类：

Remote：远程托管的MCP Server

云部署：需要在火山上创建资源自行托管的MCP Server

Local：在HiAgent平台内运行的MCP Server

安装操作：

Remote和云部署模式

选择插件，在插件详情页中单击安装。

在弹窗中单击介绍页面跳转到火山方舟MCP广场。

在广场中切换到HiAgent，并单击生成。

复制生成的URL地址。

粘贴到HiAgent平台的弹窗中。

单击确定后，该MCP将安装到当前空间的自定义插件中。

Local模式

选择插件，在插件详情页中单击安装。

在弹窗中单击获取按钮跳转到对应平台，拿到授权信息后回填表单

点击确定后，该MCP将安装到当前空间的自定义插件中。
