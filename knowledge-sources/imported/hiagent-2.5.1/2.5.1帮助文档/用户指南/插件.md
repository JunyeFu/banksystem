插件

1. 插件概述

由 HiAgent 官方或者其他用户提供的插件工具，也可以自己搭建自定义插件，这些插件涉及各类功能，如网页搜索、工具效率等，使用插件，可以帮助你拓展智能体的能力。你可以在编排或者工作流搭建时，选择使用。

支持官方插件使用，也可自定义创建插件、导入插件

支持插件的收藏和授权

支持在插件内导入工具或添加工具

支持对工具的启用/禁用，支持工具的Debug

支持插件的管理，包括删除、编辑、导入、导出、发布插件

2. 插件中心

插件中心包含以下两个入口：

应用 > 插件 > 插件中心：展示HiAgent官方或其他用户发布上架的插件，以及火山引擎云市场的插件列表。

探索 > 插件中心：展示HiAgent官方或其他用户发布上架的插件。

插件中心入口1

登录HiAgent。

进入目标工作空间，在左侧导航栏选择应用 > 插件菜单。

在插件中心页签，选择需使用的插件。在页面右上角支持切换插件列表：

插件：展示当前HiAgent插件中心的列表页，及插件总数

支持在插件中心按插件分类、权限类别、关键词模糊搜索（在插件页面可搜索工具名称），或通过收藏查看插件。

展示当前插件的插件描述、分类标签、该插件被多少智能体使用、发布时间等基本信息。

单击插件名称进入插件详情页，可查阅输入参数、输出参数等信息。

部分插件显示锁图标，使用需要先授权，在插件卡片上单击设置授权，填写授权申请后才能使用。

探索Marketplace：展示获取到的火山引擎云市场插件列表

支持关键词模糊搜索插件。

插件分类说明：

Remote：远程托管的MCP Server

云部署：需要在火山上创建资源自行托管的MCP Server

Local：在HiAgent平台内运行的MCP Server

单击插件名称进入插件详情页，可查阅插件详细介绍信息、工具列表，右上角支持快速安装插件。

插件中心入口2

登录HiAgent。

进入目标工作空间，在左侧导航栏选择探索 > 插件中心菜单。

在插件中心页面，选择需使用的插件。

默认展示全部插件、可选择我的收藏、我的提交查阅。

支持按分类筛选。

支持按需要授权、无需授权筛选。

需要授权的插件，请参考以下操作步骤进行授权：

在左侧导航栏选择应用 > 插件，在插件中心页签搜索插件名称。

在插件卡片上单击设置授权。

填写授权信息进行申请。

支持对插件收藏和取消收藏。

支持输入插件名称关键词模糊搜索插件。

支持按最近发布和最受欢迎排序。

最受欢迎：根据智能体编排里直接使用数和收藏数定义，倒序排列。

最近发布：根据插件的最近发布时间，倒序排列。

3. 自定义插件

登录HiAgent。

进入目标工作空间，选择插件后进入自定义插件页面。

可创建/导入插件和管理插件。

3.1 创建插件

3.1.1 API插件

创建插件

除了手动创建插件外，也支持导入API插件，可参考导入插件操作。

以下为手动创建插件操作：

单击创建插件，填写弹窗表单，包含插件名称、插件工具创建方式、插件描述、插件logo、插件URL、Header列表、授权方式。

手动创建工具

以下为手动创建工具操作步骤，也可以导入工具，可参考导入工具操作。

填写基本信息，配置工具的基本信息。

输入参数配置，配置工具调用的输入参数。

输出参数配置，配置工具调用返回参数。

Debug调试，配置输入参数，调试工具。

填写输入参数，并单击右下角的Debug。在页面右侧，当调试结果为绿色标识时，则调试通过，可单击完成，创建工具成功。

3.1.2 MCP插件

创建插件

在自定义插件页面，单击接入MCP插件，填写弹窗表单即可创建MCP插件。

在接入MCP插件页面，您也可以选择从Marketplace安装，自动跳转至火山引擎云市场插件列表中。单击目标插件名称进入插件详情页，在右上角单击安装，根据页面提示完成安装。

同步工具

MCP插件创建后，单击同步工具按钮导入工具列表。如果插件需要授权，则需要先填写相关授权参数，如果授权信息缺失，则无法执行导入和调试。

同步工具需要一段时间，请耐心等待。

同步成功后会覆盖之前的工具，失败则维持不变。

调试工具

由于MCP协议只定义了工具入参，未定义工具出参，直接通过listTools接口导入的工具无法被工作流调用，因此导入MCP插件需要和API插件一样，导入工具后需要进行出参解析和调试。

配置工具的基本信息。

输入参数配置，配置工具调用的输入参数，入参列表将自动从MCP Server获取，不可增删。

输出参数配置，配置工具调用返回参数。

支持自动解析，使用当前的环境变量调用一次工具，并从结果解析出参的数据结构。

Debug调试，配置输入参数，调试工具。

填写输入参数，并单击右下角的Debug。在页面右侧，当调试结果为绿色标识时，则调试通过，可单击完成，创建工具成功。

3.2 插件介绍

插件详情页支持增加插件介绍，单击介绍页签，支持以富文本或源码编辑器编写使用说明。插件上架至插件中心，支持查看插件介绍。

3.3 插件发布

插件创建完成后，在插件详情页执行发布操作。插件发布后才可以被智能体使用，已发布的插件支持更新发布。

登录HiAgent。

进入目标工作空间，在左侧导航栏选择应用 > 插件。

在自定义插件Tab页，单击插件名称进入插件详情页。

在详情页面右上角单击发布，完成插件发布。

说明：

智能体会自动使用插件最新发布的版本。

插件发布不强制要求所有工具都Debug通过。

在页面右上角单击更新记录按钮支持查看插件更新记录。

3.4 插件上架

已发布的插件支持上架到插件中心，供其他团队空间用户查找使用。

单个上架

登录HiAgent。

进入目标工作空间，在左侧导航栏选择应用 > 插件。

选择自定义插件Tab页。

在待上架插件的操作列，单击上架图标。

选择插件分类，填写插件描述后，单击确定即可完成插件的上架。

插件分类至多选择3个分类。

批量上架

登录HiAgent。

进入目标工作空间，在左侧导航栏选择应用 > 插件。

在自定义插件Tab页，单击上架插件。

选择需要上架的插件，单击下一步。

选择插件分类，填写插件描述后，单击确定即可完成插件的上架。

插件分类至多选择3个分类。

已上架的插件支持在左侧导航栏探索 > 插件中心 > 我的提交页面中查看，支持搜索关键词查询、分类查找使用。

在已上架的插件详情页单击插件中心按钮支持快速跳转至插件中心详情页。

插件上架后，你只需要再次发布就可以将修改的信息同步到插件中心。

3.5 插件管理

编辑插件

在自定义插件Tab页中，单击插件名称。

进入插件详情页，鼠标悬停在插件名称上，单击右侧编辑按钮，支持编辑插件名称等插件信息。

说明：插件被修改后，再次发布之前，智能体将继续使用之前发布版本的插件。

删除插件

在自定义插件Tab页中，单击操作列的删除按钮。

导出插件（仅API插件支持）

在自定义插件Tab页中，单击操作列的OpenAPI导出按钮。

导入插件（仅API插件支持）

在自定义插件Tab页中，单击右上角导入插件按钮，选择OpenAPI导入。导入类型为OpenApi，支持json和yaml格式文件，单个文件不超过 2 MiB。

批量导入

在自定义插件Tab页中，单击右上角导入插件按钮，选择DSL导入。

批量导出

在自定义插件Tab页中，勾选待导出的插件，在页面下方选择DSL导出，保存至本地。

配合插件批量导入功能，实现插件快速迁移。

3.6 插件工具管理

编辑工具

在插件详情页中，单击工具操作列的编辑按钮，支持修改工具名称和描述、输入参数、输出参数、debug等相关信息。

删除工具

在插件详情页中，单击工具操作列的删除按钮，支持删除单个工具。

Debug工具

在插件详情页中，单击工具操作列的Debug按钮，进入工具详情页，支持调整输入输出参数并进行调试操作。

启用/禁用工具

在插件详情页中，设置相应工具的启用/禁用开关，蓝色为启用，灰色为禁用。

查看工具被智能体的引用数

在插件详情页中，鼠标悬停在智能体引用数列的数字上，显示引用该工具的智能体名称。

查看工具输入输出

在插件详情页中，单击工具输入输出列的查看详情，支持查看工具的输入输出参数。

导入工具（仅API插件支持）

在插件详情页中，单击导入工具，支持导入OpenApi或CURL类型的工具。

OpenApi：本地上传支持导入json或yaml格式文件。

说明：OpenApi是一种用于定义和描述 API 的开放标准格式。它通常使用 JSON 或 YAML 格式来定义 API 的端点、请求方法、参数、响应等信息。通过使用 OpenApi，开发者可以更方便地了解和使用 API，同时也可以提高 API 的可发现性和可重用性。

CURL：填写工具名称、工具描述、CURL。

说明：CURL是一种命令行工具，用于在网络上发送请求和接收响应。它支持多种协议，如 HTTP、HTTPS、FTP 等。在导入插件中，CURL可能被用于与外部API进行交互，发送请求并获取响应。

## 表格 3

- 行 1: 配置项 | 说明
- 行 2: 名称 | 必填 当前工具名称命名 由中文、字母、数字、连接符（-、_）组成 不能以连接符（-、_）开头或结尾 字符限制：【2，128】字符 插件内名称唯一
- 行 3: 描述 | 必填 描述工具的主要功能和使用场景，确保内容符合平台规范。帮助用户/大模型更好地理解 字符限制：【1，500】字符
- 行 4: 工具路径 | 必填 当前工具的具体路径 以/开头，如/search
- 行 5: 请求方法 | 当前工具使用工具路径后的请求方法： GET：通过URL请求特定资源，主要用于获取数据 POST：向指定资源提交数据，常用于提交表单或上传文件 PUT：向指定位置上传数据或资源，常用于更新已存在的资源或创建新资源 DELETE：请求服务器删除指定的资源 PATCH：更新现有资源，但不创建新资源
- 行 6: 流式输出 | 配置流式输出需要勾选接入的服务支持 SSE 响应且符合平台《数据协议规范》。 流式插件适用于需要实时处理和展示连续消息流的场景，增强用户体验，例如聊天机器人和实时通知场景。 工具配置为流式输出，智能体或工作流在单次调用插件时，可以输出多条消息，每条消息能够以类似打字机的效果逐条动态显示，实现流式输出效果。
- 行 7: 超时时间 | 设置插件工具的运行超时时间，支持配置1～30分钟，默认1分钟。 该超时时间对工具自动解析出参、调试和运行都生效。 智能体、工作流、对话流要保证最长30分钟的插件运行不中断。
