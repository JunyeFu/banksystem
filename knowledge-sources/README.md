# 外部知识来源

本目录隔离第三方原件和导入资料。它们不能证明本项目当前实现，也不能覆盖 `docs`、`contracts`、代码、测试或运行证据。

- `official/`：经过来源核验的官方资料。
- `imported/`：从外部文档提取的可检索文本。
- `raw/`：DOCX、PDF、ZIP 等原件，迁移校验前本机保留、默认不提交、默认不索引。

外部资料只有在仍服务当前银行前端修复或 Coze/Harness 回归核心时才保留；失效平台、替代方案与无法验证的导入资料不得进入检索来源。

HiAgent 2.5.1 帮助资料作为外部开发参考，位于 `imported/hiagent-2.5.1/`。其导入清单、原始文件哈希和提取文本必须通过 RAG 构建与检索验证；它不能覆盖当前 Coze-only 架构，也不能进入交付系统运行时知识源。
